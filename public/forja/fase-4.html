Cómo se vigila

  • En cada cambio: tipos, lint, formato, 161 tests y build; además, una versión de prueba en Cloudflare Pages.
  • Al fusionar: se publica la web, se aplican las migraciones y se republican las Edge Functions.
  • Después, y cada lunes: la comprobación revisa la web, las cabeceras, el service worker, el modelo 3D, Gemini y la configuración de Auth, y crea un usuario temporal para probar RLS, sincronización, asistente y borrado de cuenta. El usuario se elimina siempre al final.
  • Secretos: la clave de servidor no se guarda en ningún sitio: se pide en cada ejecución a la API de gestión y se oculta en los registros.

Limitaciones documentadas

Lo que no hace

No da consejo médico ni sustituye a un profesional; no es una app de rehabilitación. MagicErick puede equivocarse y lo dice.

Lo que depende de otros

La IA en la nube usa el plan gratuito de Gemini, cuyas condiciones permiten a Google usar las preguntas: la app avisa de no escribir datos personales. La IA local necesita un ordenador con WebGPU.

Coste 0 € de verdad: Cloudflare Pages, Supabase y Gemini en sus planes gratuitos. La comprobación semanal además evita que Supabase pause el proyecto por inactividad.
